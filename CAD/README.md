# CAD Design

## Overview

The CAD model represents the mechanical structure of the parabolic solar water heater.

The design focuses on the reflector geometry, supporting structure, reflective surface and copper pipe positioned at the focal region.

## CAD Model Components

The model includes:

- Parabolic reflector
- Wooden supporting structure
- Curved metal sheet
- Reflective surface
- Copper pipe
- Pipe support brackets
- Water inlet
- Water outlet
- Base/support structure

## Parabolic Profile

The reflector is designed using:

x² = 4fy

The focal length used in the project is:

**f = 73 mm**

Therefore:

x² = 292y

The focal point is positioned approximately **73 mm above the vertex**.

## Recommended CAD Views

The project CAD documentation can include:

- Isometric view
- Front view
- Side view
- Top view
- Sectional view
- Parabolic profile
- Focal point dimension

## Purpose of CAD Model

The CAD model helps to:

- Understand the overall assembly.
- Maintain the parabolic reflector geometry.
- Position the copper pipe correctly.
- Check the supporting structure.
- Support fabrication of the prototype.
